# Public examples

`export_public_fixture.py` transforms one selected column of the packaged normalized
public tutorial fixture into long CSV. It retains the original numeric strings,
updates the input checksum and format, and writes a separate provenance record.
It refuses to overwrite an existing output directory. No expected result is
generated by this script.

`incomplete.csv` contains just the first CpG row of public reference sample
`GSM946048`, with its normalized value unchanged. It demonstrates abstention and
coverage without metadata. It is not a new reference fixture or a valid sample for
scoring. The source is `fixtures/v1/normalized-clock-probes.csv` in the packaged
Horvath registry, SHA-256
`1822620cc39b66a5ff31673ea6e1b5affd2187c4b4f209ace42b52328c509d33`.
Scientific source: Steve Horvath (2013), DOI `10.1186/gb-2013-14-10-r115`, CC BY 2.0;
normalization performed by the pinned upstream R workflow described in NOTICE.md.
